# ETH Zurich Eschikon Plant Stress Phenotyping Dataset (2018)

Local dataset repository containing downloaded files, verified metadata, and safe extractions.

- **Source Page:** [https://projects.asl.ethz.ch/datasets/doku.php?id=2018plantstressphenotyping](https://projects.asl.ethz.ch/datasets/doku.php?id=2018plantstressphenotyping)
- **Official Repository Portal:** [https://ethz-asl.github.io/datasets/plant-stress-phenotyping-2018/](https://ethz-asl.github.io/datasets/plant-stress-phenotyping-2018/)
- **Repository DOI:** [10.3929/ethz-c-000788562](https://doi.org/10.3929/ethz-c-000788562)
- **Handle:** `20.500.11850/788562`

## Directory Contents
- **`downloads/`**: Raw streamed files verified against official ETH Zurich MD5 checksums.
- **`extracted/`**: Safely extracted ZIP archives (Zip Slip protected).
- **`manifest.json`**: Machine-readable dataset manifest with file sizes, download URLs, MD5 hashes, and status.

## Excluded Files Notice
`images.zip` (~2.5 GB) is pre-downloaded by the user and is strictly excluded from download and extraction queues. Its status in `manifest.json` is marked as `excluded_already_downloaded`.
